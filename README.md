BP.TF-Auto-Relist
=================

Auto-relister for classifieds

This script automatically bumps your listings on [backpack.tf](http://backpack.tf)'s classifieds

Features:
+ Auto-Relisting
+ Automatic inclusion of trade notes
+ Automatic inclusion of item price
+ Smart pricing using market prices
+ Automatic updating of currency prices
+ Persistent mode
+ (minor) Shows number of new items
